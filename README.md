# Dhana Laxmi Decors Website

A responsive React + Vite company website for Dhana Laxmi Decors.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The production files will be generated in `dist/`.

## Free deployment

This project can be deployed free on Vercel, Netlify or GitHub Pages.

## Before publishing

- Add 5–10 real project photos to replace/extend the current reference image.
- Add a Google Maps link for the Kallakurichi address.
- Confirm phone numbers, WhatsApp number and email.
- Add social media links if the company has them.
- Connect a custom domain later if desired.
